# Command Day

Command Day is a tactical personal execution dashboard focused on daily task discipline and failure analysis.

## Stack

- React + TypeScript
- Tailwind CSS
- localStorage persistence
- framer-motion + lucide-react

## Run locally

```bash
npm install
npm run dev
```

Build production bundle:

```bash
npm run build
npm run preview
```

## Core modules

- Mission Control dashboard (daily stats + strategic phrase)
- Task checklist with priority/category/time block
- Mandatory failure modal (`Why did the mission fail?`)
- Recovery protocol panel (Acknowledge / Contain / Resume)
- Enemy Intelligence insights (weekly patterns)
- History panel and Settings
